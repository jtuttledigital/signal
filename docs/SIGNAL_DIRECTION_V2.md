# SIGNAL — Direction V2

## Updated thesis

SIGNAL visualizes the quality and progression of interaction between a person and an intelligent system.

The current continuous XY trace remains the baseline identity, but it is not a permanent hard limit. Future expressions may include:

- one dominant path
- restrained subordinate paths
- field contours
- temporary attractors
- layered depth
- structural forms
- restrained color modulation

> One system. Many expressions. Always becoming.

## Practical runtime model

### Level 1 — Universal interaction signals

Works with any AI surface:

- focus
- typing
- typing pause
- submit
- latency
- stream start
- stream cadence
- stream pause
- completion
- interruption
- idle

### Level 2 — Tool and workflow signals

Used when available:

- retrieval start and finish
- tool call start and finish
- file processing
- image generation
- code execution
- multi-step agent progress
- approval or handoff
- background work

### Level 3 — Optional semantic signals

Used only when genuinely available or transparently derived:

- task complexity
- response structure
- branching
- novelty
- confidence proxy
- uncertainty proxy
- convergence
- interaction momentum

SIGNAL must degrade gracefully when Levels 2 and 3 are unavailable.

## Visual direction families

### A. Single Path — Essence

Use for Presence, Attention, simple tasks, and clear resolution.

- one primary continuous trace
- restrained persistence
- minimal crossings
- high coherence

### B. Multi-Path Harmonics — Dialogue

Use when the interaction becomes richer or parallel work appears.

- one dominant path
- a small number of subordinate paths
- paths may split, echo, merge, or converge
- hierarchy must remain clear

### C. Field + Attractors — Thought Space

Use during active cognition and long-running work.

- restrained contour field
- temporary attractor centers
- field supports the trace rather than competing with it

### D. Structural Forms — Moments of Insight

Use when clarity or a meaningful result emerges.

- brief mathematical structures
- never literal icons by default
- appears, holds, then dissolves

### E. Layered Depth — Presence Field

Use when stronger presence or long processing needs ambient continuity.

- controlled depth
- one dominant signal remains readable
- no cinematic or HUD treatment

### F. Adaptive Complexity — Conversation Field

Use when task complexity grows.

- complexity is earned by events
- additional paths appear only when needed
- density decreases as the system converges

## Identity rules

Preserve:

- dark calm environment
- precise typography
- strong negative space
- oscillator and vector-display heritage
- deterministic mathematical generation
- smooth continuity
- restrained persistence
- observable-event-first architecture

Expand carefully:

- path count
- depth
- field behavior
- attractor variety
- color
- semantic modulation

Avoid:

- generic cyberpunk dashboards
- decorative particles without meaning
- equal visual weight across multiple paths
- random path multiplication
- pretending to reveal hidden reasoning
- constant high complexity
- telemetry presented as emotion
- color as the sole semantic carrier

## Path hierarchy

### Primary path

- represents the dominant interaction
- remains the clearest line
- owns the main transition
- stays identifiable in every state

### Secondary paths

May represent:

- alternative branches
- tool activity
- retrieved context
- parallel processing
- residual memory
- supporting harmonics

Rules:

- use the minimum number needed
- remain subordinate
- appear and disappear continuously
- converge or dissolve when no longer relevant

### Field contours

- represent latent influence and context
- remain low contrast
- may gather around active attractors

## Color direction

Cyan remains the baseline identity color.

Color may later reinforce:

- tool class
- convergence
- branch distinction
- temporary semantic emphasis
- interaction intensity

Rules:

- geometry must remain legible first
- no rainbow-by-state system
- no color dependency for accessibility
- richer color belongs to active complexity, not idle decoration
